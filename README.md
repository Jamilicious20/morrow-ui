# Morrow UI — Accessible Component Showcase

A responsive design-system showcase built with semantic HTML, CSS custom properties, and vanilla JavaScript. It has no build step or package dependencies.

## Run it

Open `index.html` in a browser. The typefaces load from Google Fonts, so an internet connection is needed for the full visual treatment. The page layout and interactions do not require a server.

## Included components and patterns

- Colour and typography foundations
- Button variants with hover, focus, and disabled states
- Labeled text fields, select, radio buttons, checkbox, and switch
- Inline feedback, dismissible alert, and live toast region
- Keyboard-operable tabs and native disclosure panels
- Native modal dialog with Escape and backdrop dismissal
- Responsive product card composition
- Light/dark theme toggle using CSS custom properties
- Skip link, visible focus states, reduced-motion support, and responsive navigation

## Portfolio notes

Before adding this project to a CV, personalize the tokens and copy, inspect it at mobile/tablet/desktop widths, and run an accessibility check with keyboard-only navigation and a screen reader. Record only results you actually measured.
